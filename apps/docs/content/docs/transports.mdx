```ts
import { createSmartRpc } from "@bloxwap/smart-rpc";
import { arbitrum } from "@bloxwap/smart-rpc/arbitrum";
import { base } from "@bloxwap/smart-rpc/base";

const rpc = createSmartRpc({ transports: [arbitrum(), base()] });
```

Each factory verifies chain identity and accepts dedicated endpoints, HTTP headers, budgets, and explicit capabilities. Review the linked notes before enabling archive state, debug/trace methods, finality tags, HTTP batches, or subscriptions.

To register a custom transport, use `createPool` and `ChainPolicy` from the package root. The complete example is in the [library reference](./reference#add-a-transport).
